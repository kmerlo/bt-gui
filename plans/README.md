## Findings considered and rejected

- NiceGUI standalone (`SPEC.nicegui.md`) — rejected for variant A; kept as archived alternative for desktop `native=True` demo. Rationale: React reuse makes Stocks_App integration trivial, NiceGUI would require rewrite.
- Monorepo `bt/bt-gui/` subfolder — rejected; separate repo keeps `git pull upstream` clean for `bt` fork. Rationale: `bt` is forked from `pmorissette/bt` and must stay pullable.
- Shared DB `config.db` + `market.db` for bt-gui — rejected; single `bt_gui.db` suffices standalone, share only at integration time if needed.
